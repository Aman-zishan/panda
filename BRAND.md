# PANDA name and logo

The PANDA name and logo identify the official PANDA project and products.

## Community use

- You may describe a project as “Built with PANDA” or “Compatible with PANDA” when accurate.
- Modified versions must use their own product name and logo.
- Make it clear when a project is independently developed and is not an official PANDA product.

## Permission required

Using the PANDA logo as product branding, or presenting a product as official,
requires permission from the project owner. Request permission through
[the project issue tracker](https://github.com/Aman-zishan/panda/issues).

## Relationship to licences

This policy covers branding. It does not grant a licence to code, hardware designs,
documentation or other assets. Those materials are governed by their applicable
licences when provided. Commercial reuse of released open-source materials is
governed by those licences; it does not imply endorsement by PANDA.

Release licences have not yet been selected. A public repository alone does not
grant open-source reuse permissions.
