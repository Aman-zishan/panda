# Repository layout

| Path | Contents |
| --- | --- |
| `docs/` | Product requirements, release plans, concept PDFs and public documentation assets |
| `site/` | Product homepage and optimized images |
| `mkdocs.yml` | Documentation theme, navigation and build settings |
| `scripts/` | Combined site build and MkDocs navigation hook |
| `.github/workflows/pages.yml` | Pull request checks and GitHub Pages deployment |
| `build/site/` | Generated homepage and searchable documentation (ignored by Git) |
| `notes/` | Local drafts and experiments (ignored by Git) |

See [Contributing](../CONTRIBUTING.md) for build instructions. The
[Stage 1 checklist](pre-hardware-checklist.md) lists directories to add when implementation begins.
Track tasks in [issues](https://github.com/Aman-zishan/panda/issues) and progress in
[milestones](https://github.com/Aman-zishan/panda/milestones).
