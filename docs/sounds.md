# Sound character

PANDA uses short, soft duck-like chirps. Routine feedback should be gentle; occasional
completion sounds can be more playful. No speech, loud honking or repeated quacking
until someone responds.

## Proposed vocabulary

| Sound | Meaning | Direction |
| --- | --- | --- |
| Listening | Ready for a command | One curious chirp |
| Understood | Action accepted or item saved | Two soft rising chirps |
| Try again | Request not understood | A questioning chirp |
| Reminder | A reminder is due | Two spaced chirps |
| Break time | Time to step away | A relaxed quack |
| Focus complete | Focus session finished | A short cheerful phrase |
| Meeting soon | A calendar meeting is approaching | Two quick, restrained chirps |
| Error | An action failed or service is unavailable | One low chirp |

Use Understood for routine acknowledgements. Knob turns, ordinary presence changes
and the running timer stay silent. Distinguish sounds by rhythm as well as pitch.
Basic uses the sounds for its local features; Connect also uses reminder and meeting
sounds. Volume control and quiet behaviour apply to both.

## Asset status

The character is agreed; this vocabulary and the final clips still need review.
`prototype.wav` was generated with ElevenLabs' free plan (confirmed 2026-11-17).
It stays in ignored working notes and is excluded from releases. It has not been
tested on PANDA's speaker.

ElevenLabs' [free-plan terms](https://elevenlabs.io/docs/overview/administration/billing)
limit use to non-commercial purposes with attribution. Its
[Sound Effects terms, Exhibit 4](https://elevenlabs.io/creative-terms) also restrict
distribution as isolated audio files. This clip is not suitable for PANDA's reusable
public sound assets; a paid plan alone would not resolve that distribution restriction.
Release clips need a source that permits commercial reuse and redistribution.

Before release, record each clip's source and licence and check it on the actual
speaker. AI-generated prototypes are not automatically cleared for a public release.
